# Rent Herning website

Source for the new rentherning.dk: a static site with Rent Herning's listings from Boligportal, a 3D model of central Herning on the home page, and a guided help and contact flow for tenants. Danish at `/`, English at `/en/`.

**Demo:** https://rentherning.github.io/website/
